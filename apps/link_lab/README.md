# `link_lab` — cFS Data Link Layer Application

`link_lab` is a cFS application written in Rust that implements a CCSDS data link layer (TM, AOS, and USLP downlink transfer frames; TC and USLP uplink transfer frames with MAP demultiplexing and segment reassembly; and COP-1 FARM-1) using [Aldis](https://github.com/kscharpf/aldis), running unmodified on cFS v7.0.1 (`pc-linux` PSP).

## 1. Overview & Crate Boundaries

| Crate / Path | Role | Constraints |
|---|---|---|
| [`apps/link_lab/core`](core) (`link-lab-core`) | Sans-I/O link state machine (`Link`, `Level`, `Variant`, `DownlinkState`, `UplinkState`, `UplinkMode`, `LinkConfig`) | `#![no_std]`, `#![forbid(unsafe_code)]`, heap-free, panic-free, workspace flight lint set; depends on `aldis` and `refapp-scenario` only; no `cfe` or `cfe-sys` dependency |
| [`apps/link_lab`](.) (`link-lab`) | Thin cFS `staticlib` glue (`LINK_LAB_AppMain`, SB pipe dispatch, `step-lab-core::msg` wire encode/decode) | `#![cfg_attr(not(test), no_std)]`, `#![deny(unsafe_code)]` with one `#[expect]` on `LINK_LAB_AppMain`; linked with `--undefined=LINK_LAB_AppMain`, `--gc-sections`, and `link_lab.sym` (exports only `LINK_LAB_AppMain`) |
| [`crates/cfe`](../../crates/cfe) | Safe Rust wrappers over cFE (`es`, `evs`, `sb`, `msg`, `status`) and OSAL (`osal::TcpStream`, `osal::task_delay`) | `#![no_std]`; all app-side `unsafe` lives here with `// SAFETY:` comments; free of `aldis` |
| [`crates/cfe-sys`](../../crates/cfe-sys) | Raw `extern "C"` declarations and `#[repr(C)]` types generated by `bindgen` from `node_defs` mission headers | `#![no_std]`; declarations only; committed `src/bindings.rs` verified current on every `make node` run |

In the node test configuration, `link_lab` runs alongside four companion apps and a shared SB helper crate:

- **`step_lab`** ([`apps/step_lab`](../step_lab)): Bridge to `refapp-harness` over loopback TCP (`osal::TcpStream`) and lockstep sequencer (`START`, `WAKE_RX`, `WAKE_CMD`, `WAKE_HK`, `WAKE_PL`, `WAKE_TX`, `DONE`). Free of `aldis`.
- **`cmd_lab`** ([`apps/cmd_lab`](../cmd_lab)): Scenario command handler, time-tag queue, table store, and memory dump app built on `refapp-flight` modules.
- **`hk_lab`** ([`apps/hk_lab`](../hk_lab)): Periodic housekeeping telemetry app built on `refapp-flight::Downlink` and `refapp-flight::layout`.
- **`pl_lab`** ([`apps/pl_lab`](../pl_lab)): Periodic payload telemetry app built on `refapp-flight::Downlink` and `refapp-flight::layout`.
- **`node_glue`** ([`apps/node_glue`](../node_glue)): Shared `#![no_std]`, `#![forbid(unsafe_code)]` SB message glue (`prepare_msg`, `send_sb_msg`, `send_done`, `send_tlm_packet`, `send_record_event`). Free of `aldis`.

## 2. Build & Verification

Run from the repository root:

| Target | Environment | What it runs |
|---|---|---|
| `make check` | Host | `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` (includes `link-lab-core` unit tests and A1–A4 differential tests against the golden traces) |
| `make rs` | Container | Builds cFS with the Rust MSG module (`modules/msg` / `cfe-msg-ffi`), runs `ctest -R coverage-msg` (`coverage-msg-ALL`), and runs [`scripts/check-symbols.sh`](../../scripts/check-symbols.sh) |
| `make node` | Container | Runs [`scripts/cfs-node.sh`](../../scripts/cfs-node.sh): builds `core-cpu1` (`MISSIONCONFIG=node`, `MISSION_DEFS=node_defs`) on both stock MSG (`node-stock`) and Rust MSG (`node-rs`), verifies `crates/cfe-sys/src/bindings.rs` freshness via `bindgen`, runs [`scripts/check-app-symbols.sh`](../../scripts/check-app-symbols.sh) on `link_lab.so`, `step_lab.so`, `cmd_lab.so`, `hk_lab.so`, and `pl_lab.so` (single exported entry point, no heap symbols, no panic/unwind symbols), and runs all 16 `refapp-harness` cases (`a0-empty`, `a1-*`, `a2-*`, `a3-*`, `a4-aos-nominal`, `a4-uslp-nominal`) twice per build (64 runs), checking byte-for-byte golden trace equality and start-up EVS events |

## 3. Integration Requirements

### Mission & target configuration (`node_defs/targets.cmake`)

Add the applications and startup script to the target CPU configuration in [`node_defs/targets.cmake`](../../node_defs/targets.cmake):

```cmake
SET(cpu1_APPLIST link_lab step_lab cmd_lab hk_lab pl_lab)
SET(cpu1_FILELIST cfe_es_startup.scr)
include("${CMAKE_CURRENT_LIST_DIR}/check_msgids.cmake")
```

### Message IDs (`node_defs/node_msgids.h`)

Internal bus message IDs are defined in [`node_defs/node_msgids.h`](../../node_defs/node_msgids.h) outside cFE's reserved platform and global ranges (`0x0800..=0x087F` telemetry, `0x1800..=0x187F` command):

- Commands / turns: base `0x1900` (`NODE_CMD_MID_BASE`)
- Telemetry / data: base `0x0900` (`NODE_TLM_MID_BASE`)
- Harness TCP port: `NODE_HARNESS_PORT` (`5010`)

`_Static_assert` checks (`NODE_CHECK_MID`) verify at compile time that no node MID collides with cFE reserved ranges.

### Startup script & stack sizing (`node_defs/cpu1_cfe_es_startup.scr`)

Each app is started in [`node_defs/cpu1_cfe_es_startup.scr`](../../node_defs/cpu1_cfe_es_startup.scr) with a **64 KiB (`65536` bytes)** task stack because state and packet/frame buffers are held on the task stack with zero heap allocation:

```text
CFE_APP, link_lab, LINK_LAB_AppMain, LINK_LAB, 60, 65536, 0x0, 0;
CFE_APP, cmd_lab,  CMD_LAB_AppMain,  CMD_LAB,  65, 65536, 0x0, 0;
CFE_APP, hk_lab,   HK_LAB_AppMain,   HK_LAB,   66, 65536, 0x0, 0;
CFE_APP, pl_lab,   PL_LAB_AppMain,   PL_LAB,   67, 65536, 0x0, 0;
CFE_APP, step_lab, STEP_LAB_AppMain, STEP_LAB, 70, 65536, 0x0, 0;
```

### Pipe depth & POSIX `fs.mqueue.msg_max`

`link_lab`, `cmd_lab`, `hk_lab`, `pl_lab`, and `step_lab` create Software Bus pipes of depth **32** (`LINK_LAB_PIPE`, `CMD_LAB_PIPE`, `HK_LAB_PIPE`, `PL_LAB_PIPE`, `STEP_LAB_PIPE`) and use `Pipe::subscribe_ex` with per-MID limits up to **32** (cFE's default `CFE_PLATFORM_SB_DEFAULT_MSG_LIMIT` of 4 is smaller than a step's burst of telemetry packets).

On Linux (`pc-linux` PSP), OSAL silently truncates POSIX message queues to `/proc/sys/fs/mqueue/msg_max` (often 10 by default) without returning an error. Ensure `fs.mqueue.msg_max >= 32` (the [`Makefile`](../../Makefile) passes `--sysctl fs.mqueue.msg_max=64` to the container). At start-up, `step_lab` runs `cfe::sb::check_pipe_depth(32, NODE_TEST_MID)` and exits with a Critical EVS event if queue truncation is detected.

## 4. Internal Software Bus Interface

Scenario Space Packets travel wrapped inside internal Software Bus messages ([`apps/step_lab/core/src/msg.rs`](../step_lab/core/src/msg.rs), design §4.4) rather than as native cFE messages. Wrapping avoids MID collisions with cFE platform telemetry (e.g., APID `0x010` would map to `0x0810` in MID v1) and keeps scenario secondary headers untouched by cFE header routines.

| Message | MID | From → To | Payload | Purpose |
|---|---|---|---|---|
| `START` | `0x1900` (`NODE_START_MID`) | `step_lab` → `link_lab`, `cmd_lab`, `hk_lab`, `pl_lab` | `LinkLevel` (`Packets`, `Frames`, `Cop1`), `LinkVariant` (`TmTc`, `Aos`, `Uslp`) | Initializes app state for the case after `HELLO` |
| `WAKE_RX` | `0x1901` (`NODE_WAKE_RX_MID`) | `step_lab` → `link_lab` | `now`, one link unit (≤ 1024 B) | Process one delivered uplink unit |
| `WAKE_TX` | `0x1902` (`NODE_WAKE_TX_MID`) | `step_lab` → `link_lab` | `now`, `tx_slot` | Drain buffered `TLM_PACKET`s and pipe, then emit slot unit |
| `WAKE_CMD` | `0x1903` (`NODE_WAKE_CMD_MID`) | `step_lab` → `cmd_lab` | `now` | Execute due time-tagged commands and dump segments |
| `CMD_PACKET` | `0x1904` (`NODE_CMD_PACKET_MID`) | `link_lab` → `cmd_lab` | `now`, one command packet | Deliver one extracted command packet (step 1) |
| `CMD_PACKET_DONE` | `0x1905` (`NODE_CMD_PACKET_DONE_MID`) | `cmd_lab` → `link_lab` | — | Return turn after handling one command packet |
| `WAKE_HK` | `0x1906` (`NODE_WAKE_HK_MID`) | `step_lab` → `hk_lab` | `now` | Run housekeeping periodic step |
| `WAKE_PL` | `0x1907` (`NODE_WAKE_PL_MID`) | `step_lab` → `pl_lab` | `now` | Run payload periodic step |
| `TEST` | `0x190F` (`NODE_TEST_MID`) | `step_lab` → `step_lab` | — | Startup pipe-depth truncation self-check |
| `TLM_PACKET` | `0x0900` (`NODE_TLM_PACKET_MID`) | `cmd_lab` / `hk_lab` / `pl_lab` → `link_lab` | One telemetry packet (≤ 1024 B) | Submit telemetry packet for downlink |
| `RECORD` | `0x0901` (`NODE_RECORD_MID`) | `cmd_lab` / `hk_lab` / `pl_lab` / `link_lab` → `step_lab` | `RecordKind` (`PacketOut`, `PacketIn`, `Event`), APID/code, data/args | Trace output record in production order |
| `UNIT` | `0x0902` (`NODE_UNIT_MID`) | `link_lab` → `step_lab` | One link unit (≤ 1024 B) | Downlink unit output |
| `DONE` | `0x0903` (`NODE_DONE_MID`) | `link_lab`, `cmd_lab`, `hk_lab`, `pl_lab` → `step_lab` | `next_deadline` (`Option<u64>`) | Ends the app's turn and reports earliest deadline |
| `SCN_STATUS` | `0x0904` (`NODE_SCN_STATUS_MID`) | `cmd_lab` → `hk_lab`, `pl_lab` | `ScnStatus` | Broadcast scenario status snapshot after `START` and `WAKE_CMD` |
